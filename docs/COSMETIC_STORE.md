## 使用

GM 商城选择「全部特殊外观」，或衣装、风之翼、游迹、武器外观、名片分类。
选顶部在线玩家 UID 后点击「免费解锁」。重新进入相应装扮页面查看已解锁内容。
已经拥有的商品再次点击仅返回已拥有，不增加库存或扣币；修改兑换价格后须从游戏内购买。

## 解锁与装备

- 解锁依据实际外观 ID，独立于商品 ID 和刷新限购，旧账号自动获得空武器外观列表。
- 衣装及游迹必须匹配角色；武器外观必须与角色武器类型匹配，0 表示卸下。
- 武器外观批量更换先校验全部角色，失败不会只更换一部分。
- 重登录发送完整武器外观所有权和装备角色；场景与队伍信息发送已装备武器外观。
- 千星服饰使用已有 BeyondCloset 所有权和解锁通知；商城中的部件和套装共用所有权判断。
